# Образцы текстов от SEO

Четыре книги Excel — контент четырёх готовых сайтов, по одному файлу на сайт. Присланы как образец
того, что приходит от SEO: с них берётся структура, тематика и уклон, а тексты генерируются заново
под свой бренд.

Лежат в репозитории намеренно. Это единственный настоящий пример входных данных, и без него любая
работа над генерацией текстов упирается в «покажите файл».

## Что внутри

У всех четырёх одни и те же восемь листов — это страницы сайта:

```
Home  Casino  Slots  Games  Betting  Bonus  App  Login
```

Формат листа описан в [docs/spreadsheet-format.md](../../docs/spreadsheet-format.md): столбец A —
метка строки (`title`, `description`, `h1`, `h2`, `table` или пусто), столбец B — текст, пустая
строка делит разделы.

## Как превратить в страницы

```bash
npm run import:sheet -- "data/examples-new/https___899ok.win_.xlsx" имя-папки
```

Книга читается с диска (`scripts/xlsx.mjs`) и дальше идёт тем же путём, что таблица по ссылке.
Результат — папка сайта в `data/sites/`.

## Что показала проверка

Все 32 страницы конвертируются без единого предупреждения, всего 387 блоков. Форма страницы у всех
одна, различается только длина:

```
hero → toc → 7–11 разделов → [links] → faq
```

Блок «другие страницы» есть у двух сайтов из четырёх. Число разделов на странице — от 7 до 11.
