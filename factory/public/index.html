Фабрика сайтов

Бренд, гео, шаблон и список страниц → тексты, картинки, логотип и готовый сайт в output/

Основное
Шаблон и контент

data/sites/[папка] — новое имя или одна из тех, что уже есть

«Случайно» — каждой странице свой пример из тех, что есть у неё

Папка должна уже быть. Бренд, гео и язык тогда можно не заполнять — возьмутся из site.json

Иначе перед сборкой делаются логотип, если его нет, и картинки для меток image, которых нет в images.json

Нарисует новый логотип, даже если он уже есть — случайный стиль из восьми в logo.json. Примерно $0.07 за сборку

Страницы

Те, для которых у шаблона есть примеры. Адрес страницы — её имя, home обязательна

Страница, которая уже написана, не переписывается

Сайт и партнёрка

Пустое поле — имя папки берётся от папки с сайтом

Пустое поле — берётся partnerUrl из site.json выбранного сайта
